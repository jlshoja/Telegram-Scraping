# Telegram Scraping — Project Documentation (for humans + future agents)

> Purpose: scrape Persian handbag Telegram channels, extract product attributes
> from post text via regex and fill a product Excel database.
> Folder: `E:\Luxbaz\All Codes\Projects\01-New_Luxbaz_Product\Telegram Scraping`

---

## 1. What this project does (business logic)

1. **Scrape** 5 Telegram channels (handbag sellers) with Telethon → cache raw posts.
2. **Parse** each Persian post text to extract 4 attributes:
   - `ابعاد` (dimensions, e.g. `15×27`)
   - `جنس` (material, e.g. `شرانگ وارداتی`)
   - `نوع بند` (strap type)
   - `کاربرد` (usage: `دوشی | روزمره | اداری | مجلسی | کوله | پاسپورتی`, or fallback `دسته بندی` value)
3. **Match** each row in `Product Database.xlsx` (key = `کد محصول` like `FA-1959`, `TR-402`, `BA-1481`, `SHK-649`, `MR-5161`, `MK-100231`) to the best Telegram post containing that code.
4. **Fill** `Product Database - filled.xlsx` (never touches the source file) + derive `دسته بندی` from `کاربرد` (`کیف دوشی زنانه` etc.).
5. **Report** everything to `report.txt` (filled / not-found / ambiguous status).

Current scale (Oct 2026): ~1637 cached posts, 1419 Excel rows.

## 4. Excel schema (critical for agents)

| `دسته بندی` (col 6) | category | derived from `کاربرد` via `usage_to_category()` |

| `ابعاد` (col 11) | dimensions | filled from `extract_fields` |
| `جنس` (col 12) | material | filled |
| `نوع بند` (col 13) | strap type | filled |
| `کاربرد` (col 14) | usage | filled |
| `رنگ` | color | not filled by script |

`fill.py` hardcodes: `FIELDS = ["ابعاد","جنس","نوع بند","کاربرد"]`, `COL = {ابعاد:11, جنس:12, نوع بند:13, کاربرد:14, دسته بندی:6}`.
It asserts `کد محصول, فروشنده, دسته بندی` + FIELDS headers exist or exits `missing column: X`.

`usage_to_category("دوشی | پاسپورتی")` → `"کیف دوشی زنانه | کیف پاسپورتی زنانه"` (prefix `کیف`, suffix `زنانه` unless already starts with `کیف`).

## 5. Pipeline

```
Telegram channels.XLSX
        │ scrape.py (Telethon, incremental)
        ▼
cache/posts.json  [{channel, id, date, text(normalized)}]
        │ fill.py: build_index() → exact{FA-1959}, nums{1959}
        │        + seller_affinity + best_candidate()
        ▼
Product Database.xlsx ──► Product Database - filled.xlsx
                              ▼
                          report.txt
```

### 5.1 `scrape.py` — fetch

Key functions (`scrape.py`):

- `parse_proxy(url)` — `socks5://user:pass@host:port` → Telethon tuple `(scheme, host, port|1080, True, user, pass)`, else `None`.
- `read_channels()` — col A from `Telegram channels.XLSX` row 2+, strip, skip empty.
- `link_to_target(link)` — `t.me/xxx?y` → `("username","xxx")`; `+HASH` → `("invite","HASH")`.
- `resolve(client, kind, value)` — username → `client.get_entity` (None on `UsernameNotOccupied/ChannelPrivate`); invite → `ImportChatInviteRequest` (handles `UserAlreadyParticipant→CheckChatInvite`, None on `InviteHashInvalid/Expired/InviteRequestSent`).
- `ensure_auth(client, args)` — if authorized return; else phone → `send_code_request` → code from `--code` / stdin / `cache/pending_code.txt` (polls 600s) → `sign_in`, handles 2FA `SessionPasswordNeededError` via `--password`/`TG_PASSWORD`/prompt; `--login` flag exits after auth.
- `load_cache()/save_cache()` — read/write `cache/posts.json` (saved every 200 new posts + per channel + end).
- `fetch(args)` — main loop: for each channel `iter_messages(entity, limit=args.limit)` (None = all), skip empty text, dedup `(title, msg.id)`, append `{channel:title, id, date:str, text:normalize(text)}`.
- CLI: `--login, --code, --password, --phone, --limit INT, --wait-file`.

Idempotent: re-runs only append unseen `(channel,id)`.

### 5.2 `tgcommon.py` — text normalization + extraction

- `normalize(text)` — FA/AR digits → ASCII (`۰۱۲۳..`+`٠١٢٣..`), `ك→ک`, `ي/ى→ی`, `–/—→-`. Applied at scrape time AND before every extraction (idempotent).
- `extract_fields(text) -> {ابعاد?, جنس?, نوع بند?, کاربرد?}`:
  - `ابعاد`: `DIM_AFTER_WORD` (`ابعاد|سایز` + junk + `DIM|DIM_SLASH`) else any `DIM_ANY` (`\d{1,4}(/​\d)? [*×xX] ...` up to 3 parts); spaces stripped.
  - `جنس`: `جنس` + junk + `([^\n،,;|]+)`, cut at next keyword/newline/punct via `_cut()`.
  - `نوع بند`: prefer `نوع\s*بند` + value → `_trim_band()` (strip `_BAND_STOP` tails like ` هم داره/داره/میشه...`, unbalanced parens, cap 8 words); fallback `BAND_PHRASE` (`بند` not preceded by `نوع /digit/letter`, not `بندی`) guarded by `_band_ok()` (reject if value starts with `بندی`, has digits, or `قیمت` on same line before match).
  - `کاربرد`: keyword scan `CAT_KEYWORDS=[دوشی,روزمره,اداری,مجلسی,کوله,پاسپورتی]` joined `" | "` (dedup, order of list); else `دسته\s*بندی` + value.
  - `_JUNK = [^\w\n]{0,15}?` lets emoji/punctuation sit between keyword and value. `_NEXT_KEYWORDS=[نوع بند,دسته بندی,ابعاد,سایز,کد,رنگ,قیمت,تعداد,مدل]` used by `_cut()`.
- `extract_codes(text) -> (exact{FA-1959:code_kw|full}, nums{1959:...})`:
  - `CODE_AFTER` (`کد[محصول|کالا|کلیدی|شناسه]?|code` + junk + `([A-Za-z]{0,6}[-]?\d{2,7})`) → `code_kw` (higher trust). Bare digits also accepted.
  - `FULL_CODE` (`\b([A-Za-z]{2,6})\s*[-–]\s*(\d{2,7})\b`) → `full`.
  - Keys uppercased, format `PREFIX-NUMBER`.

### 5.3 `fill.py` — match + fill

Functions:

- `build_index(posts)` → `(exact{CODE:[(mtype,fields,post)]}, nums{NUMBER:[...]})`. Each post parsed once with `extract_fields`+`extract_codes`.
- `build_seller_affinity(code_rows, nums)` — `{(seller, channel): weight}`; weight 3 if `code_kw` else 1. Captures "seller X's codes mostly appear in channel Y".
- `score(mtype, fields)` = `60 (code_kw) | 40 (full) + 2*len(fields)`.
- `best_candidate(cands, affinity)` — sort by `(affinity[channel], score, len(fields), len(text))` desc; returns `(top, tie_count>1?flag)`.
- `usage_to_category(usage)` — see §4.
- `main(args)` flow:
  1. Load posts, build index. Load workbook, resolve header names→columns.
  2. Parse rows: `code=normalize(str).upper()`, `m=re.match(^([A-Z]+)-(\d+)$)`. `--codes FA-1,TR-2` filters.
  3. Seller affinity from `[(row,seller,num)]`.
  4. Per row: empty→`no_code`; bad format→`invalid`; `cands = exact[code] or nums[number]` else `not_found` (+3 hint posts containing digits); affinity for this seller → `best_candidate` (ties→`ambiguous`); empty fields→`found_empty`; else write FIELDS cells only if empty unless `--refresh` (else `kept_existing`), count `filled_rows`.
  5. Derive `دسته بندی` from `کاربرد` (skip if filled unless `--refresh`).
  6. Save `DST`, write `REPORT` sections (see §8), print summary.
- CLI: `--refresh, --codes "FA-1,TR-2"`.

Matching priority: exact code match beats bare-number match; `code_kw` (near `کد`) beats loose `PREFIX-NUM`; seller's usual channel wins; richer post wins. Bare-number fallback can mismatch — check `ambiguous` + hints in report.

### 5.4 `build_woocommerce.py` — WooCommerce import sheet

Builds `woocommerce_import_new.xlsx` from `Product Database - filled.xlsx`, mirroring the `woocommerce_import.xlsx` template (37 headers in identical order) plus one new pair: `attribute:material` / `attribute_name:material` (`جنس`).

- Source columns looked up **by header name**: `کد محصول`, `نام محصول `, `اسامی محصولات`, `دسته بندی`, `قیمت فروش`, `قیمت فروش تخفیف خورده`, `ابعاد`, `جنس`, `کاربرد`, `رنگ`.
- Parent (`product`): title `{نام محصول} کد {کد}` (fallback `اسامی محصولات`; `ندارد`/empty → row skipped); sku = full code; `regular_price` ← `قیمت فروش` (missing → row skipped); `sale_price` + `sale_tag=تخفیف خورده‌ها` ← discount col (same value on parent + all variations); `manage_stock=yes`, parent stock empty; categories `کیف زنانه>{value}` joined ` | `; images all empty; attributes only when non-empty: color (`رنگ` names joined `|`), application (`کاربرد`), material (`جنس`), dimention (`ابعاد` raw).
- Variations (`product_variation`, one per color): sku `{code}-{english-slug}`, same prices/tag, stock from `رنگ` pair (`آبی-2 | سبز-3`; Persian digits ok; missing number → `ناموجود` + warning), only color attribute.
- Slugs: learned at runtime from the template file (`EXTRA_SLUGS` overrides, e.g. `عسلی→honey`); unknown colors skip that variation + warn (add slug to `EXTRA_SLUGS`).
- Row selection: valid `PREFIX-NUMBER` codes only; duplicates skipped. CLI: `--codes`, `--src`, `--template`, `--out`.
- `run.bat` option 6 runs it.

## 8. Known quirks / troubleshooting (read before changing code)

1. `Product Database.xlsx` (SRC) absent → `fill.py` crashes at `load_workbook`. Restore it or adjust `SRC` const.
2. `Telegram session expired` → `python scrape.py --login`.
3. `found post but no field extracted` (e.g. `کد1990 قیمت390` only) → post has no attributes; expected for price-only posts.
4. `code not found` → code never posted (or different prefix spelling); hints list posts containing bare digits.
5. `ambiguous (N tied)` → N posts scored equally; first taken. Disambiguate via seller affinity or manual check.
6. `existing values kept` with `I2*1.3`-style values → placeholder formulas from earlier manual edit; use `--refresh` to overwrite.
7. `scrape.log` Persian garbled → stdout was cp1252; scripts now force UTF-8 (`reconfigure`). Use `chcp 65001` / UTF-8 editor.
8. Private channel needs invite link in `Telegram channels.XLSX`; expired invite → `SKIP cannot access`.
9. `woocommerce_import_*.xlsx` is downstream/manual — scripts don't read/write it.

## 9. Cookbook for future agents

- **Add channel:** append URL to `Telegram channels.XLSX` col `link` → `python scrape.py` → `python fill.py`.
- **Add output field** (e.g. `رنگ`): extend `extract_fields()` in `tgcommon.py` + add to `FIELDS`/`COL` in `fill.py` (find column index from header), test with `--codes`.
- **Fix bad parse:** add regex/regression in `tgcommon.py`; test: `python -c "from tgcommon import extract_fields; print(extract_fields('...'))"`.
- **Change category rule:** edit `usage_to_category()` in `fill.py`.
- **Fresh rescan of one channel:** delete its posts from `cache/posts.json` or lower `--limit` for test.
- **Debug match for one code:** `python fill.py --codes FA-1959` then read `report.txt` filled/ambiguous/not-found sections.
- **Never:** commit `.env`, `cache/`, `*.session`; never write to `Product Database.xlsx` (only `- filled.xlsx`); keep Persian headers byte-identical.
